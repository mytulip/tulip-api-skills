Sur un brouillon (draft), cet endpoint annule la pré-déclaration : elle passe en archived (webhook v2.claim.draft.archived). Sur une pré-déclaration soumise ou un sinistre hors pré-déclaration, il abandonne le sinistre que Tulip instruit : il passe en abandoned (webhook v2.claim.abandoned), sans retour possible par l'API. L'abandon est refusé si un paiement est en cours (409, code 3007) ou si le sinistre n'est plus ouvert (409, code 3003). settlements ne liste que les paiements effectués : un paiement en cours bloque l'abandon sans y apparaître.
