Cet endpoint permet de récupérer les détails complets d'un sinistre. L'identifiant peut être celui de la pré-déclaration (id) ou celui du sinistre (claimId). Fonctionne aussi pour un sinistre hors pré-déclaration, avec l'identifiant du sinistre. Le statut du sinistre (in_progress, pending_info, closed, rejected, abandoned) se lit ici, pour une pré-déclaration soumise comme pour un sinistre hors pré-déclaration.
