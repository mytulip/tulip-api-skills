Cet endpoint permet de soumettre un sinistre pour traitement. Tous les documents obligatoires doivent avoir été déposés. Le sinistre peut aussi être soumis automatiquement lorsque tous les documents obligatoires sont fournis. Pour un sinistre hors pré-déclaration, la soumission est refusée (409), comme pour une pré-déclaration déjà soumise.
